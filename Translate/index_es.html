Lunacy

Política de Privacidad

Fecha de Efecto: 27 de septiembre de 2025

1. Introducción

Bienvenido a Lunacy, un bot de Discord diseñado para mejorar la experiencia de tu servidor con comandos divertidos, herramientas de moderación y funciones comunitarias. Esta Política de Privacidad explica cómo recopilamos, usamos, divulgamos y protegemos tu información cuando usas nuestro bot en la plataforma Discord.

2. Información que Recopilamos

Recopilamos los siguientes tipos de información:

  • Datos de Usuario de Discord: Nombre de usuario, ID de usuario, ID de servidor, mensajes, reacciones y otras interacciones con el bot. Estos datos son proporcionados por la API de Discord y son necesarios para que el bot funcione.
  • Datos del Servidor: Información del gremio (servidor), detalles de canales y asignaciones de roles para habilitar funciones del bot como moderación y comandos personalizados.
  • Datos de Uso: Registros de comandos del bot usados, marcas de tiempo y informes de errores para mejorar el rendimiento y depurar problemas. No se almacena información personal identificable más allá de lo requerido para la operación.
  • Análisis: Datos agregados y anonimizados sobre el uso del bot en servidores para entender tendencias y mejorar funciones.

3. Cómo Usamos tu Información

Usamos la información recopilada para:

  • Proporcionar y mantener la funcionalidad del bot, como responder a comandos y gestionar interacciones del servidor.
  • Mejorar el bot a través de análisis y retroalimentación.
  • Asegurar la seguridad y prevenir abusos, como detección de spam.
  • Comunicar actualizaciones o avisos importantes a través de canales de Discord.

4. Compartir tu Información

No vendemos ni compartimos tu información personal. Los datos pueden compartirse con:

  • Discord Inc. según sus términos de API.
  • Servicios de terceros para hosting y análisis (p. ej., datos anonimizados a Google Analytics), que cumplen con GDPR/CCPA.

En caso de requisitos legales, podemos divulgar datos a las autoridades.

5. Almacenamiento y Seguridad de Datos

Los datos se almacenan en servidores seguros (p. ej., Heroku o similares) con encriptación en tránsito (HTTPS) y en reposo. Período de retención: 30 días para registros, indefinido para IDs de usuario esenciales a menos que se eliminen. Usamos medidas de seguridad estándar de la industria para proteger contra acceso no autorizado.

6. Tus Derechos

Bajo GDPR (UE) o CCPA (CA), tienes derechos para acceder, corregir, eliminar o oponerte al procesamiento de datos. Contáctanos a través de Discord o email (si se proporciona) para ejercer estos derechos. Para administradores de servidores, puedes remover el bot para detener la recopilación de datos.

7. Privacidad de Niños

Nuestro bot no está destinado a niños menores de 13 años. Discord tiene su propio cumplimiento COPPA.

8. Cambios a Esta Política

Podemos actualizar esta política. Los cambios se anunciarán en el servidor de Discord del bot o vía comando.

9. Contáctanos

Para preguntas, contacta al desarrollador del bot en [your-email@example.com] o a través del servidor de Discord.

Términos de Servicio

Fecha de Efecto: 27 de septiembre de 2025

1. Aceptación de Términos

Al invitar a Lunacy a tu servidor de Discord o usar sus comandos, aceptas estos Términos de Servicio ("Términos"). Si no estás de acuerdo, no uses el bot. Los administradores de servidores son responsables del cumplimiento en sus servidores.

2. Descripción del Servicio

Lunacy es un bot de Discord que proporciona entretenimiento, moderación, comandos de utilidad y herramientas comunitarias. Las funciones incluyen respuestas divertidas, gestión de roles y integraciones personalizadas, sujetas a los límites de la API de Discord.

3. Elegibilidad del Usuario

Debes tener al menos 13 años y cumplir con los Términos de Discord. El bot es solo para uso no comercial.

4. Conducta del Usuario

Aceptas no:

  • Usar el bot para actividades ilegales, acoso o spam.
  • Ingeniería inversa, modificación o distribución del código del bot.
  • Sobrecargar servidores o violar límites de tasa.
  • Personificar a otros o difundir desinformación.

Nos reservamos el derecho de banear usuarios o remover el bot de servidores que violen estos Términos.

5. Propiedad Intelectual

Lunacy y sus funciones son propiedad del desarrollador. No puedes copiar ni reclamar propiedad. Las marcas de Discord son propiedad de Discord Inc.

6. Descargos de Responsabilidad y Limitaciones

El bot se proporciona "tal cual" sin garantías. No somos responsables por pérdida de datos, tiempo de inactividad o daños indirectos. La responsabilidad se limita a $100. Usa bajo tu propio riesgo.

7. Terminación

Podemos suspender o terminar el acceso en cualquier momento por violaciones. Puedes remover el bot de tu servidor.
